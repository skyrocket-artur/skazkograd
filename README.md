# Сказкоград

Игра для детей 3–4 лет: буквы, цифры, цвета и фигуры в народных сказках. Механики узнаваемых игр 2000-х («Ну, погоди!», Тетрис, Змейка, тир с Денди, Angry Birds, Cut the Rope), без проигрышей, рекламы и покупок. Работает как статичный сайт на GitHub Pages.

Пять сказок по пять уровней: Колобок, Теремок, Репка, Три медведя, Золотая рыбка. Сейчас готов мир 1 «Колобок», остальные четыре на карте помечены «Скоро». Озвучка — голос «Марина» из библиотеки ElevenLabs.

## Запуск у себя

```bash
python3 tools/serve.py 8791
```

Открыть http://localhost:8791. Сервер отдаёт файлы без кэша, чтобы после правок не смешивались старые и новые версии. С телефона в той же Wi-Fi-сети: `http://<адрес Mac>:8791`.

Полезные адреса:
- `?level=w1l3` — сразу открыть уровень;
- `?test=1&auto=1&speed=4` — робот проходит весь мир на ускорении ×4, ошибки складываются в `G.errors`;
- `?test=1&auto=1&level=w1l4&speed=1` — робот играет один уровень с обычной скоростью.

## Устройство

| Файл | Что внутри |
|---|---|
| `js/core.js` | настройки (`G.CONFIG.shareUrl` — куда ведёт «Поделиться»), сохранение прогресса, утилиты |
| `js/audio.js` | синтез звуков и музыки, озвучка пакетами, голос браузера как запасной |
| `js/lines.js` | все реплики; по ним генерируется озвучка |
| `js/art.js` | все рисунки (векторные SVG в коде) |
| `js/game.js` | движок уровня: canvas, ввод, подсказки, выбор ответа, защита от зависаний |
| `js/ui.js` | экраны: заставка, карта, тропинка, «сказка пройдена», родители, «Поделиться» |
| `js/levels/w1.js` | пять уровней «Колобка» |
| `sw.js` | офлайн-кэш (игра работает и без него) |

Правила, чтобы игра не тупила:
- озвучка никогда не держит касания;
- озвучка мира грузится заранее одним файлом;
- звук будится на каждом касании;
- графика не скачивается;
- если в уровне что-то падает, ребёнок видит кнопку «Дальше», а не зависший экран.

## Озвучка (ElevenLabs)

Ключ должен лежать в `ELEVENLABS_API_KEY` (в `~/.zshrc`).

```bash
node tools/voice.mjs --voices
node tools/voice.mjs --sample <voice_id> <voice_id>
node tools/voice.mjs --voice <voice_id>
```

Первая команда показывает голоса аккаунта, вторая делает пробы в `audio/samples/`. Третья генерирует все реплики и собирает `audio/c.mp3`, `audio/w1.mp3` и `js/voice-packs.js`. Если поменять текст в `js/lines.js` и запустить её снова, перегенерируются только изменённые реплики.

## Выкладка

```bash
node tools/bump.mjs
```

Скрипт меняет версию в `sw.js` и `?v=` в `index.html`. Запускать перед каждым пушем: GitHub Pages кэширует файлы на 10 минут.
