# Сказкоград

Игра для детей 3–4 лет: буквы, цифры, цвета и фигуры в народных сказках. Механики узнаваемых игр 2000-х («Ну, погоди!», Тетрис, Змейка, тир с Денди, Angry Birds, Cut the Rope), без проигрышей, рекламы и покупок. Работает как статичный сайт на GitHub Pages.

Пять сказок по пять уровней: Колобок, Теремок, Репка, Три медведя, Золотая рыбка. Готовы все пять миров, 25 уровней, около часа игры. После «Золотой рыбки» ребёнок получает грамоту знатока Сказкограда. Озвучка — голос «Марина» из библиотеки ElevenLabs.

## Запуск у себя

```bash
python3 tools/serve.py 8791
```

Открыть http://localhost:8791. Сервер отдаёт файлы без кэша, чтобы после правок не смешивались старые и новые версии. С телефона в той же Wi-Fi-сети: `http://<адрес Mac>:8791`.

Полезные адреса:
- `?level=w1l3` — сразу открыть уровень;
- `?test=1&auto=1&speed=4` — робот проходит весь мир на ускорении ×4, ошибки складываются в `G.errors`;
- `?test=1&auto=1&level=w1l4&speed=1` — робот играет один уровень с обычной скоростью.

## Устройство

| Файл | Что внутри |
|---|---|
| `js/core.js` | настройки (`G.CONFIG.shareUrl` — куда ведёт «Поделиться»), сохранение прогресса, утилиты |
| `js/audio.js` | синтез звуков и музыки, озвучка пакетами, голос браузера как запасной |
| `js/lines.js` | все реплики; по ним генерируется озвучка |
| `js/art.js` | все рисунки (векторные SVG в коде) |
| `js/game.js` | движок уровня: canvas, ввод, подсказки, выбор ответа, защита от зависаний |
| `js/ui.js` | экраны: заставка, карта, тропинка, «сказка пройдена», родители, «Поделиться» |
| `js/levels/common.js` | общий лесной фон и помощники для уровней |
| `js/levels/w1.js` | пять уровней «Колобка» |
| `js/levels/w2.js` | пять уровней «Теремка» |
| `js/levels/w3.js` | пять уровней «Репки» |
| `js/levels/w4.js` | пять уровней «Трёх медведей» |
| `js/levels/w5.js` | пять уровней «Золотой рыбки» и финал |
| `sw.js` | офлайн-кэш (игра работает и без него) |

Правила, чтобы игра не тупила:
- озвучка никогда не держит касания;
- озвучка мира грузится заранее одним файлом;
- звук будится на каждом касании;
- графика не скачивается;
- если в уровне что-то падает, ребёнок видит кнопку «Дальше», а не зависший экран.

## Озвучка (ElevenLabs)

Ключ должен лежать в `ELEVENLABS_API_KEY` (в `~/.zshrc`).

```bash
node tools/voice.mjs --voices
node tools/voice.mjs --sample <voice_id> <voice_id>
node tools/voice.mjs --voice <voice_id>
```

Первая команда показывает голоса аккаунта, вторая делает пробы в `audio/samples/`. Третья генерирует все реплики и собирает `audio/c.mp3`, `audio/w1.mp3` … `audio/w5.mp3` и `js/voice-packs.js`. Если поменять текст в `js/lines.js` и запустить её снова, перегенерируются только изменённые реплики.

### Ударения

Без подсказки голос ElevenLabs ставит ударения неверно («те́ремок», «ло́пай → лопа́й», «нево́дом»). Поэтому перед отправкой в ElevenLabs `tools/voice.mjs` ставит знак ударения (U+0301) в каждое слово по словарю `tools/stress.txt`. Если в новой реплике есть слово, которого нет в словаре, генерация останавливается: допиши слово в `stress.txt` с ударением. Омографы («до́ма», «в кружке́», «са́мого») проверяй по смыслу. Если в одной реплике нужно другое ударение, поставь знак прямо в `js/lines.js`: в субтитрах его не видно.

```bash
node tools/voice.mjs --text w2_intro   # что уйдёт в ElevenLabs
```

Результат проверяет `tools/stress_check.py`. Он распознаёт звуки речи моделью wav2vec2 и для каждого слова сравнивает варианты ударения: ударная гласная полная и длинная, безударная редуцированная (о → а, е → и). Если звук лучше объясняет другое ударение, слово попадает в список. Знак ударения голос слушается не всегда, поэтому реплики из списка нужно перезаписать: удали их mp3 из `audio/src/` и строки из `audio/src/index.json`, запусти `voice.mjs` и проверь снова. Слово, которое ошибается во всех дублях, лучше заменить. Около половины слов по звуку не различить (только «и», «у», «ы»): для них остаётся словарь.

```bash
python3 -m venv .venv && .venv/bin/pip install torch transformers
.venv/bin/python tools/stress_check.py            # все реплики
.venv/bin/python tools/stress_check.py w2_intro   # одна реплика
```

При первом запуске скачивается модель facebook/wav2vec2-xlsr-53-espeak-cv-ft (1,3 ГБ).

## Выкладка

```bash
node tools/bump.mjs
```

Скрипт меняет версию в `sw.js` и `?v=` в `index.html`. Запускать перед каждым пушем: GitHub Pages кэширует файлы на 10 минут.
